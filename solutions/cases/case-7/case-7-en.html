REAL CASE №7

Automatic consolidation of data from hundreds of Excel files

Employees from different stores regularly upload Excel reports to a shared folder. Each file has the same structure but is not convenient for direct analysis: it contains service rows, repeated headers, intermediate totals and data arranged in separate blocks.

PROBLEM

The analyst collected data manually from a large number of files

New reports arrived every week from stores and regional divisions. To prepare consolidated analytics, the analyst had to open every file, copy the data and add it to a master table.

  • hundreds of separate Excel files;
  • manual copying of data;
  • risk of missing a new file;
  • duplicates and structural errors;
  • many hours spent on repetitive work.
SOLUTION

One connection to the folder and automatic refresh

The analyst connects Power Query or Power BI to the shared folder only once. During each refresh, the system finds new files, cleans the tables, converts the data to a consistent format and combines everything into one dataset.

  • automatic detection of new files;
  • validation of the expected structure;
  • removal of service rows;
  • duplicate control;
  • analytics refreshed with one button.
